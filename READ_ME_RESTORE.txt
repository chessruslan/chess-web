MAKECHESS SAFE RESTORE

1. Extract BOTH files into any one folder:
   RESTORE_MAKECHESS_WORKING.cmd
   restore_makechess_working.sh

2. Double-click:
   RESTORE_MAKECHESS_WORKING.cmd

This does not compile a new version.
It restores the newest server backup that contains the known working
Supabase configuration.

The temporary SMOKE button may return because the restored version is
the last known fully working site. That is intentional.
