MAKECHESS LOCAL STOCKFISH SILENT V1

Purpose:
- Remove the large Local Stockfish window from normal use.
- Keep the local HTTP bridge alive silently in the background.
- Restart the bridge automatically if it stops.
- Leave the MakeChess website logic untouched.
- The website button remains only a NETWORK / LOCAL source switch.

Install:
1. Extract all 3 files into:
   C:\SUPER_Makechess_Video_NEW_DISINE_4_Ocenka
2. Run:
   19_INSTALL_LOCAL_STOCKFISH_SILENT_V1.cmd
3. Wait for:
   LOCAL_STOCKFISH_SILENT_V1_OK

No PUBLISH_MAKECHESS.cmd is required.
