MAKECHESS ADMIN DELETE V8.3

Добавлено:
- кнопка УДАЛИТЬ в той же зоне административных действий;
- удалить нельзя, пока администратор не написал причину;
- никаких новых окон: первое нажатие раскрывает подтверждение прямо в общей панели;
- причина отправляется пользователю ДО удаления и остаётся в истории;
- турниры удаляются через существующий TournamentStorageService.deleteTournament();
- игрок / школа / учитель получают постоянную административную отметку удаления
  и исчезают из административного каталога;
- запись административного архива можно удалить отдельной кнопкой;
- удаление записи архива подтверждается прямо внутри строки архива;
- admin_delete считается административным сообщением и поддерживает ответ пользователя;
- все новые строки добавлены централизованно на RU EN DE FR ES AR ZH HI JA KO VI.

ВАЖНО:
Текущее окно Настройки сайта использует локальный административный пароль.
Поэтому V8.3 НЕ пытается небезопасно удалять чужой Supabase Auth-account из браузера.
Для игрока/школы/учителя V8.3 делает административное удаление (tombstone).
Настоящий hard-delete аккаунта на сервере нужно подключать отдельным защищённым admin RPC.

Команда:
  .\INSTALL_MAKECHESS_ADMIN_DELETE_V8_3.cmd
