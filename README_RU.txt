MAKECHESS DESKTOP V1 — НЕЗАВИСИМОЕ WINDOWS-ПРИЛОЖЕНИЕ
=======================================================

Что сделано
-----------
1. Турниры работают локально без сайта и без Supabase.
2. Локальные данные зеркалируются в обычные JSON-файлы в:
   Документы\MakeChess\Tournaments
3. Экспорт/импорт .mct работает и в Web, и в Windows-приложении.
4. Убраны прямые dart:html-зависимости из менеджера и редактора турниров,
   чтобы эти экраны могли собираться под Windows.
5. Добавлена автоматическая проверка обновлений Windows каждые 15 минут.
   При наличии новой версии приложение скачивает установщик, проверяет SHA-256,
   запускает тихое обновление и закрывает старую копию.
6. Добавлены скрипты сборки MakeChess.exe и установщика.
7. Данные турниров лежат вне папки программы, поэтому обновление их не удаляет.

Куда копировать
---------------
Скопируйте содержимое этого архива В КОРЕНЬ вашего Flutter-проекта.
Пути lib/... должны совпасть с существующими путями проекта.

ВАЖНО: перед заменой сделайте git commit или резервную копию.

Первая сборка Windows
---------------------
1. Откройте корень проекта.
2. Запустите BUILD_MAKECHESS_WINDOWS.cmd
3. Скрипт сам создаст папку windows, если её ещё нет.
4. Результат:
   build\windows\x64\runner\Release\MakeChess.exe

Если Flutter сообщит, что не хватает Visual Studio Desktop C++ workload,
установите "Desktop development with C++" в Visual Studio Installer.

Создание нормального установщика
--------------------------------
1. Установите Inno Setup 6.
2. Запустите BUILD_MAKECHESS_INSTALLER.cmd
3. Результат:
   build\installer\MakeChessSetup-1.0.0.exe
4. Скрипт также создаст desktop\update.json с SHA-256.

Как работает автоматическое обновление
--------------------------------------
Приложение проверяет:
  https://makechess.com/desktop/update.json

На сервере должны лежать два файла:
  /desktop/update.json
  /desktop/MakeChessSetup-X.Y.Z.exe

При выпуске версии 1.0.1:
1. В pubspec.yaml поставить version: 1.0.1+2
2. Запустить BUILD_MAKECHESS_INSTALLER.cmd
3. Загрузить на makechess.com:
   build\installer\MakeChessSetup-1.0.1.exe
   desktop\update.json
4. Установленные приложения сами обнаружат версию 1.0.1.

Поведение без интернета
-----------------------
- MakeChess.exe запускается независимо от makechess.com.
- Турниры читаются с компьютера.
- Создание турнира, участники, жеребьёвка, туры, результаты, таблица и архив
  не должны зависеть от базы.
- Сетевые функции (приглашения, онлайн-игра, видеосвязь, облачная публикация)
  требуют интернет.
- Когда интернет вернётся, локальные изменения можно синхронизировать.

Локальная папка
---------------
Windows-версия создаёт:
  Документы\MakeChess\Tournaments

Там находятся зеркала локальной базы. В самом менеджере турниров в окне
недоступности базы есть кнопка "Папка локальных данных".

Безопасность обновлений
-----------------------
Обновление устанавливается только если SHA-256 скачанного EXE точно совпадает
со значением в update.json. Следующим этапом желательно также подписать
установщик сертификатом Authenticode.
