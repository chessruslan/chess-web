MAKECHESS LOCAL STOCKFISH TEXT FIX V5

Что исправляет:
- убирает кракозябры на кнопке локального Stockfish;
- показывает состояние прямо на кнопке: ВКЛ / ВЫКЛ;
- переводит кнопку и сообщения на 11 языков сайта;
- при смене языка надпись на кнопке меняется сразу;
- логику локального/сетевого Stockfish НЕ меняет.

Языки:
RU, EN, DE, FR, ES, AR, ZH, HI, JA, KO, VI.

Установка:
1. Распаковать всё в корень проекта:
   C:\SUPER_Makechess_Video_NEW_DISINE_4_Ocenka
2. Запустить 12_FIX_LOCAL_STOCKFISH_TEXTS_V5.cmd
3. Дождаться LOCAL_STOCKFISH_TEXT_FIX_V5_OK
4. Запустить PUBLISH_MAKECHESS.cmd
5. На makechess.com нажать Ctrl+F5

Перед изменениями автоматически создаётся резервная копия трёх файлов.
