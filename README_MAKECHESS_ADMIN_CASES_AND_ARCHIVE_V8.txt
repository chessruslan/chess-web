MAKECHESS — ADMIN CASES + ARCHIVE V8

Цель
====
Расширить "Настройка сайта" до общей административной панели без скрытых
санкций.

Главное правило V8:
  НЕТ СООБЩЕНИЯ -> НЕТ БЛОКИРОВКИ / ОГРАНИЧЕНИЯ.

Администратор сначала пишет объяснение. Только после этого становятся доступны:
- Отправить сообщение
- Отправить предупреждение
- Применить ограничения
- Заблокировать

Предупреждение
==============
В том же окне можно включить:
  "Напомнить мне проверить ситуацию"

Срок по умолчанию: 10 дней.
Срок можно менять.

Когда срок истёк:
- НИКАКОЙ автоматической блокировки;
- статус становится "Срок истёк — требуется решение администратора";
- в административной панели появляется красное напоминание;
- решение принимает администратор после проверки.

Отклик пользователя
===================
Обычное окно "Сообщения" получает поддержку административных сообщений.

Пользователь видит:
- текст администратора;
- срок, если он задан;
- "Ответить";
- "Сообщить, что исправлено".

Ответ возвращается администратору и показывается в той же административной
карточке и истории.

Одна панель, без цепочки окон
=============================
Для Игроков / Школ / Учителей / Турниров справа используется одно рабочее
пространство, разделённое на зоны:
1. Объект и статус
2. Административное действие / текст
3. Предупреждение + необязательный таймер
4. Ограничения
5. Действия
6. История + ответ пользователя

Турниры
=======
В разделе "Турниры" можно открыть выбранный турнир через существующий
TournamentTableEditor.

Архив
=====
Добавлен пункт "Архив" с 4 режимами:
- Пользователи
- Партии
- Турниры
- Школы / Учителя

В шапке есть "Что сохранять":
- Сохранять пользователей
- Сохранять партии
- Сохранять турниры
- Сохранять школы и учителей

Архив отделён от блокировок.

Текущий этап сохраняет административную историю и настройки архива.
Полноценное серверное долговременное архивирование всех исторических партий
нужно подключать отдельным этапом к базе данных — V8 не выдумывает несуществующую
серверную таблицу.

Данные и ограничения
====================
Административные сообщения используют существующий MakeChess
MakeChessMessageRealtimeService, но V8 направляет категории admin_* в
проверенную таблицу public.makechess_messages_v1. Поэтому обычные
административные сообщения не маскируются под приглашения на турнир.
Realtime используется для быстрой доставки онлайн, база — источник доставки
после следующего входа.

Сами административные кейсы/таймеры/выбранные ограничения в V8 пока
сохраняются через SharedPreferences административного клиента. Это означает:
- интерфейс, история, таймеры и двусторонняя переписка работают;
- глобальное серверное принуждение блокировок по всем устройствам ещё НЕ
  подключено. Для него нужен отдельный серверный moderation store / таблица
  и проверки прав в точках входа.

Это сделано намеренно: V8 не меняет схему БД без отдельного согласования.

Локализация
===========
Все НОВЫЕ видимые строки V8 сразу добавляются в центральный файл:
  lib\localization\makechess_localization.dart

Языки:
  RU EN DE FR ES AR ZH HI JA KO VI

V8 не создаёт отдельный языковой файл.

Файлы
=====
Новый:
  lib\ui\dialogs\admin_management_panel.dart

Хирургически патчатся:
  lib\ui\dialogs\site_settings_dialog.dart
  lib\ui\messages\general_messages_dialog.dart
  lib\localization\makechess_localization.dart

Установщик:
- делает точные backup текущих файлов;
- использует структурные маркеры, а не старые полные копии;
- запускает dart format, если Dart доступен;
- при ошибке восстанавливает всё.

Установка
=========
1. Распаковать ZIP в корень проекта.
2. Запустить:

  .\INSTALL_MAKECHESS_ADMIN_CASES_AND_ARCHIVE_V8.cmd

3. Только после:
   DONE: ADMIN CASES + ARCHIVE V8 installed.

запустить:

  .\PUBLISH_MAKECHESS.cmd

Не считать V8 скомпилированным до реального вывода Flutter build.
