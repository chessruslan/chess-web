MAKECHESS — ADMIN CASE WORKFLOW V8.4

Реализовано:
- административные кнопки активны сразу после выбора объекта;
- после нажатия открывается одно окно с обязательным объяснением;
- подтверждение в окне неактивно, пока текст пустой;
- предупреждение имеет необязательный таймер в том же окне;
- таймер только напоминает админу, автоматической блокировки нет;
- в карточке выделяется самое первое письмо как «ПЕРВОНАЧАЛЬНАЯ ПРИЧИНА»;
- первое письмо не редактируется;
- ниже видна вся переписка по этому административному делу в хронологическом порядке;
- после ответа можно снять/сохранить ограничения, разблокировать/оставить блокировку,
  восстановить/оставить удалённым; новое решение снова требует объяснения;
- ответ пользователя в основном окне «Сообщения» открывает точную карточку и точное дело;
- «Настройка сайта → Сообщения» показывает ответы пользователей;
- у пункта «Сообщения» в настройке сайта есть красный счётчик непрочитанных ответов;
- основной красный счётчик сообщений использует уже существующий unreadMessages верхней панели;
- все новые системные фразы добавляются в центральную локализацию на 11 языках:
  RU EN DE FR ES AR ZH HI JA KO VI.

Техническое ограничение:
V8.4 не создаёт серверный hard-delete и не меняет RLS/схему production БД.
Настоящий серверный режим «удалён, разрешены только сообщения» требует отдельного
защищённого статуса/RPC/RLS. Это сознательно не выполняется скрыто установщиком.

Установка:
  .\INSTALL_MAKECHESS_ADMIN_CASE_WORKFLOW_V8_4.cmd

После DONE сначала показать вывод установки. Публикацию отдельно.
