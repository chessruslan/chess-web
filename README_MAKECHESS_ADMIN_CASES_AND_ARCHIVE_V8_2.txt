MAKECHESS — ADMIN CASES + ARCHIVE V8.2

Что исправлено относительно V8.1
--------------------------------
V8.1 сравнивал makechess_localization.dart по SHA256.
Это оказалось слишком строгой проверкой: предыдущие установщики локализации
запускают dart format, поэтому содержательно правильный текущий V7-файл
может иметь другой байтовый hash.

V8.2:
- НЕ заменяет makechess_localization.dart целиком;
- НЕ требует от него точного SHA256;
- проверяет маркеры V6/V7 и структуру MakeChessLocalization;
- хирургически добавляет только V8-блок переводов и его lookup;
- сохраняет все текущие V7-переводы и форматирование;
- site_settings_dialog.dart и general_messages_dialog.dart по-прежнему
  защищены точной проверкой, потому что V8.1 уже подтвердил их совпадение;
- при любой ошибке восстанавливает резервные копии.

Новая административная механика та же:
- Игроки / Школы / Учителя / Турниры / Архив;
- одно общее окно административного действия;
- невозможно заблокировать/ограничить без текста причины;
- предупреждение с необязательным таймером;
- таймер только напоминает админу, автоматической блокировки нет;
- пользователь может Ответить или сообщить «Исправлено»;
- ответы и история видны в том же административном кейсе;
- Архив: Пользователи / Партии / Турниры / Школы-Учителя;
- новые строки переведены на RU EN DE FR ES AR ZH HI JA KO VI.

Команда:
  .\INSTALL_MAKECHESS_ADMIN_CASES_AND_ARCHIVE_V8_2.cmd

После DONE пока не публиковать — сначала показать результат установки.
