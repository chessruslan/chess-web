MAKECHESS — TOURNAMENT UI LOCALIZATION V7

Проверены все присланные пользователем турнирные файлы:
- student_tournaments_dialog.dart
- tournament_game_platform_dialog.dart
- tournament_manager_dialog.dart
- tournament_pairing_control_dialog.dart
- tournament_participant_picker_dialog.dart
- tournament_table_editor.dart
- makechess_localization.dart

Почему для замены нужен только один файл
----------------------------------------
В турнирных Dart-файлах видимый русский текст уже выводится через
MakeChessLocalizedText / MakeChessLocalization.phrase.

Оставшаяся проблема была в центральной локализации:
1. helper формировал подпись как "Тип турнира:" — с двоеточием, а словарь
   содержал "Тип турнира" без двоеточия;
2. в словаре отсутствовал ряд турнирных фраз, enum-подписей и динамических
   строк.

V7 исправляет это централизованно, поэтому турнирную логику заменять не надо.

Добавлено
--------
- безопасный fallback для известных UI-подписей с двоеточием;
- 52 точные турнирные UI-фразы на 11 языках;
- 9 динамических шаблонов на 11 языках;
- участник/соперник/ничья;
- режимы жеребьёвки;
- типы и системы турниров;
- управление партией;
- варианты видео/досок;
- динамические "Доска N", "Видео N", "Рейтинг: N", "Участников: N" и др.

Важно
-----
Пользовательские данные НЕ переводятся:
- название турнира "ЗИМА";
- имена игроков;
- школа;
- введённый судья;
- пользовательское место проведения;
- другие произвольные данные.

Установка:
  .\INSTALL_MAKECHESS_TOURNAMENT_UI_LOCALIZATION_V7.cmd

После DONE:
  .\PUBLISH_MAKECHESS.cmd
